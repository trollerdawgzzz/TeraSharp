## Compatibility details

- `set_admin_level` retains TeraSharp account-level authorization; native is character-scoped. `set_go` now has a character override, while the TERASHARP_GM_ACCOUNTS authorization floor remains project policy.
- `party N` is the explicitly requested T200 synthetic-member extension; retail syntax is named users. The native name syntax remains supported.
- `profile`/`reset_profile` send the native World1447/1448 broadcasts. C++ Arbiter function/packet instrumentation and its native profiler files do not exist in this runtime; that local portion is explicitly reported as unavailable.
- `open_awesomium` sends client7D57; it does not launch a browser on the server. `cc`/`clientCommand` address the caller, with the first argument as command name rather than target character.
- Human-owned integration is in `status/T201-PATCH.diff`. Native-derived tests are labeled separately from captured inputs in `data/t201/captured-commands.json`.
