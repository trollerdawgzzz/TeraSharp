### Fix decision and next live check

**Keep retail packet behavior.** Normal accounts already have no Huddle package; the retail
tutorial restriction applies to all accounts independently. No benefit/quest/blob changes are justified.
On the now-relocated T181 character in continent **7031**, run `/@allow_teleport off`, then retry
atlas/Vanguard and capture both streams. If it succeeds there, the continent gate explains this run.
If it still refuses, record source/destination and read agent+0x58, User+0xA410, +0xB628, +0xA6B8,
class +0x1438 and loaded restriction/class sheets; packets alone cannot prove those runtime values.

Two **optional, unapplied policy patches** target the World `Executable` directory, not this repo:

- [T182-TELEPORT-POLICY.diff](T182-TELEPORT-POLICY.diff): one line changes `target="all"` to
  `target="benefitOnly"`, allowing ordinary non-Huddle accounts through this tutorial agent.
  This deliberately differs from the captured retail rule; it is not a missing Arbiter packet fix.
- [T182-HUDDLE-FALLBACK.diff](T182-HUDDLE-FALLBACK.diff): the requested minimum AccountTrait
  fallback changes the three package HuddleAdding `enable` values to false; the default is already false.
  **This alone cannot disable the target=all teleport gate.** Fresh World startup/login is required
  for a deterministic data-change test; do not assume a live XML edit cleared an existing User flag.
